# Satchel desktop audit · 11 November 2026

Reviewed the full checkout of `thesiyonara/satchel` at `a1a9c5b`, one commit past the 0.6.20 release. The review covered the desktop and web branding, native tray setup, collection import entry points, locked dependencies, update and signing workflows, and the repository’s automated checks. The original clone passed `git fsck --full`.

## Findings and changes

| Finding | Change | Verification |

## Checks performed on Apple silicon

- TypeScript and production build passed. All 40 unit tests and both sync integration tests passed.
- Desktop UI, floating-window/CLI features, update preparation, phone web client and two-app transfer suites passed with isolated profiles.
- Built both the Mac ZIP and DMG. The Documents volume attached Finder metadata during signing, so the verified build was packaged on a local temporary volume. Deep strict bundle signature verification and the pinned helper check passed.
- The final packaged app passed its startup smoke test, including the five Electron fuses, ASAR integrity, authenticated helper, CLI note capture/read and clean shutdown.

## Outstanding evidence

The full npm audit reports six moderate build-time entries tracing back to two installations of `minimatch` in the Electron packaging toolchain. The installed builder is 26.18.0. Its declared dependency range excludes the patched major. Revisit when the builder and universal packager support a patched version.

Windows installation, a physical phone and a new inter-device Windows–Mac acceptance run were outside this Mac test run. The local build retains version 0.6.20. Its changes need to reach a future GitHub release to persist through that update.
