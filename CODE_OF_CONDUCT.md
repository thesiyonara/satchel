# Code of conduct

Be respectful and specific. Discuss the work, not the person. Assume good intent, and ask before assuming context someone did not give.

Harassment, personal attacks, discriminatory remarks and publishing someone's private information are not acceptable anywhere in this project: issues, pull requests, discussions or commits. Maintainers may edit, hide or remove such content and block repeat offenders.

If something happens that you do not want to raise publicly, contact the maintainers through GitHub's private vulnerability reporting on this repository with "conduct" in the title, and it will be read the same way.
